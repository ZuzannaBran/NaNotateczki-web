04 / MOŻLIWOŚCI EDYTORA

Więcej niż odręczne pismo.

Cztery sposoby wymazywania

Eraser brush usuwa fragmenty kresek, Erase stroke całe kreski, Erase area wybrany obszar, a Scratch erase pozwala wymazać pismo przez zamazywanie bazgrołami.

Linie i kształty

Jak zainstalować aplikację?

Informacje przydatne po udostępnieniu plików instalacyjnych.

01

Pobierz instalator przeznaczony dla swojego systemu z tej strony.

02

Otwórz pobrany plik i postępuj zgodnie z instrukcjami systemu.

03

Jeżeli system wyświetli ostrzeżenie o nierozpoznanym wydawcy, upewnij się, że plik pochodzi z oficjalnego źródła.

Dlaczego system może ostrzegać przed instalacją?

NaNotateczki jest niezależnym projektem. Niepodpisane cyfrowo lub jeszcze nierozpoznane instalatory mogą wywoływać ostrzeżenia Windows SmartScreen, macOS Gatekeeper albo Androida. Sam komunikat nie przesądza, czy plik jest szkodliwy, ale nie należy go ignorować bez weryfikacji źródła.

Windows: komunikat „System Windows ochronił ten komputer” może udostępniać opcję „Więcej informacji”. Kontynuuj tylko wtedy, gdy plik pobrano z tej strony i masz pewność co do jego pochodzenia.

Android: przy instalacji APK poza sklepem system może poprosić o zgodę dla aplikacji instalującej plik. Udzielaj jej wyłącznie zaufanemu źródłu.

macOS: w przypadku blokady sprawdź informacje o pochodzeniu programu w „Prywatność i ochrona”. Linux: AppImage może wymagać nadania uprawnienia wykonywania pliku.
